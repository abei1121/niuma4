# video_caption_styler

## 核心职责
1. **关键词情感与数值挖掘**：
   - 自动提取数值、百分比（如 `90%`, `3万`）
   - 自动识别警告/避坑词（如 `千万别`, `致命`, `陷阱`, `底层逻辑`）
   - 自动标注搞钱/干货高光词（如 `暴利`, `翻倍`, `顶级`, `逆袭`）
2. **多层级视觉样式生成**：
   - `Default` 基础样式：纯白文字 + 粗黑描边
   - `Highlight` 高光样式：高饱和柠檬黄 + 阴影浮雕，吸引视觉焦点
   - `Alert` 警示样式：警示绯红 + 粗描边，强化风险与痛点
3. **屏幕安全区层级坐标铁律**：
   - 底栏动态花字字幕必须显式配置 `ClipSettings(transform_y=-0.72)`，严禁留在默认 `y = 0.0` 中心位置（避免遮挡出镜人脸）。
4. **黄金前 3 秒钩子悬念轨分离**：
   - 0.0s~3.5s 提取全片最具反差的核心标题作为独立 `黄金前3秒钩子轨`（金红醒目配色、加大字号居中吸睛）。
5. **pyJianYingDraft 多文本轨显式规约**：
   - 动态花字轨、钩子轨与顶栏标牌轨共存时，必须显式传递 `track="动态花字轨"` 或 `track="黄金前3秒钩子轨"`，杜绝默认隐式添加导致的 NameError。
