# 紫微斗数全息数理事实树标准规范 (Fact Tree Schema)

## 一、事实树定位与宪章
事实树是紫微斗数排盘算法向大语言模型（LLM）交付的唯一先验数理全账。
其定位为：**客观事实与数理推论的绝对中枢，大模型推演的不可动摇证据底座**。
大模型回答任何问题，**必须且只能以事实树内记录的数据为准，严禁凭空捏造未列出的星曜或流化**。

---

## 二、标准事实树五层拓扑结构

事实树自上而下严格分为五层结构：

### 1. 第一层：历法天体与物理基准
- `乾坤性别`: 男命 / 女命
- `地理经度`: 精确至小数点后三位（如 `116.400°E`）
- `钟表时间`: 输入的标准时区时间
- `真太阳时`: 根据经度差（4分钟/度）与天体均时差（Equation of Time）实时校准后的物理时间
- `农历日期`: 正统干支纪年、月、日
- `正统四柱`: 正统紫微正月初一换年干支柱
- `节气四柱`: 八字立春换年四柱
- `五行局数`: 水二局 / 木三局 / 金四局 / 土五局 / 火六局
- `生年天干`: 锁定生年四化之根源
- `来因宫`: 来因宫不落子丑，逢子视寅，逢丑视卯
- `命主 / 身主 / 子年斗君 / 身宫寄处`

### 2. 第二层：当前时空动态坐标 (限运叠盘)
- `当前大限`: 步入某天干地支大限，叠本命某宫，大限运化四化
- `当前流年`: 当年岁次流年，叠本命某宫，流年四化
- `当前小限`: 虚岁 N 岁，小限天干地支，落本命某宫，小限四化
- `当前流月 / 流日`: 流月与流日落位及相应四化

### 2.5 核心时空层：天人地三盘重叠与流年四化冲合专栏 (Triple Superposition Engine)
- **近五年流年太岁全景穿透**（如 2024~2028）：
  - 每一年的太岁干支、虚岁与大限命宫坐标；
  - 流年命宫地支、叠本命某宫、叠大限某宫之**三盘重叠拓扑 (Triple Superposition)**；
  - 流年天干四化（禄/权/科/忌）各星曜的落入地支与三盘重叠；
  - **流年化忌星直冲靶心（💥 Clash Target）**：明确计算冲破对宫之本命、大限、流年宫位，封死大模型心算漏算；
  - 流年流曜落位（流禄、流羊、流陀、流马）。

### 3. 第三层：数理先验推演总纲 (断命核心)
- **八十年大限时空演进总纲**：按顺逆起运次序，逐一列出 8 个大限的起止年龄、大限宫位、运化星曜；
- **钦天门象数因果定数总纲**：
  - 1. 来因定极
  - 2. 生年四化定数与内外宫归属（六内宫主自得实益，六外宫主施他外散）
  - 3. 离心自化 (↓) 能量消散与破耗防线
  - 4. 向心自化 (↑) 外部机缘与宿命引动
  - 5. 宫干飞忌网络
  - 6. 钦天大限定数应期（踩中生年四化、来因宫或自化忌之大限）
  - 7. 钦天绝对破耗警示（自化忌冲对宫之极端破败象）
- **中州派星系格局总纲**：
  - `0. 格局定品`: 纯代码判定的正统吉凶格局（如【火贪格】、【三奇嘉会格】、【铃昌陀武格】）
  - `1. 命宫` / `2. 迁移宫` / `3. 官禄宫` / `4. 财帛宫`: 主星亮度、六吉星、六煞星
  - `5. 身宫后天立极`: 35 岁后人生发力重心与心理归宿

### 4. 第四层：十二宫全盘微观数据 (逐宫展开)
每个宫位标准展开格式：
```
│ ├XX[天干地支] [来因宫]
│ │ ├限流叠宫: 本命[XX] · 大限[XX] · 流年[XX] · 小限[XX]
│ │ ├主星: 紫微[廟](┏ 科) ...
│ │ ├辅星: 左辅,右弼 ...
│ │ ├大限流曜 / 流年流曜
│ │ ├小星与神煞 (岁前、将前、长生十二神、博士十二神)
│ │ ├大限: XX大限 (XX-XX岁)
│ │ ├太岁流年: 地支年 [YYYY(N岁), YYYY(N岁)...] (完整列至85岁)
│ │ └小限虚岁: N, N+12, N+24... 岁
```

### 5. 第五层：符号定义与流派注记
- 明确标注三大流派融合准则：以钦天为骨（象数定数），以中州为肉（星系现实画面），以身宫立极（后天修持破局）。
