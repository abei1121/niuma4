# 钦天门象数因果网络与定理法典 (Qintian Theorems Canon)

## 一、钦天门核心数理哲学
钦天门以“象、数、理、气”为宗，强调**因果定数与时空应期**。
如果中州派是人生的“舞台布景与角色血肉”，钦天门就是人生的“底层剧本逻辑与业力引力场”。

## 二、六大数理公理 (Mathematical Axioms)

### 1. 来因定极公理 (Lai Yin Palace)
- **定义**：出生年干所落之宫位（根据五虎遁天干起月遁出）；
- **铁律**：来因宫不落子丑（若落子宫视寅，落丑宫视卯）；
- **本质**：一生业力与使命之源头。来因在夫妻主情缘纠葛，来因在官禄主事业造化，来因在财帛主体力经济。

### 2. 内外宫聚散公理 (Inner vs Outer Palaces)
- **六内宫**：命宫、财帛、官禄、田宅、疾厄、福德（主自得实益、资本固化沉淀、归于自身）；
- **六外宫**：迁移、交友、夫妻、子女、兄弟、父母（主施他外散、机缘流动、为他人作嫁衣）。

### 3. 生年四化定数公理 (Birth Mutagens)
- **生年禄 (┏ 禄)**：资本、财富、缘起、福分；入内宫一生温饱不愁，入外宫利人脉社交但财易外散；
- **生年权 (┏ 权)**：权力、掌控、技术、争夺；入内宫掌控全局专业权威，入外宫受制于人或多竞争；
- **生年科 (┏ 科)**：名誉、贵人、解厄、文教；入内宫清心从容贵人护佑，入外宫名声在外；
- **生年忌 (┏ 忌)**：执念、归宿、欠债、劳顿；入内宫欠债自身拼命劳碌，入外宫亏欠他人多纠缠。

### 4. 自化能量矢量公理 (Self-Transformation Vectors)
- **离心自化 (↓)**：
  - 宫干向外射出自身星曜化象；
  - 主该宫能量散逸、留不住、缘起缘灭不执著；
  - 逢自化忌为系统防御破口，不可死守硬抗。
- **向心自化 (↑)**：
  - 对宫宫干射入本宫之化象；
  - 主外部时空主动送来资源、机遇或宿命合伙人，应期一到自然入局。

### 5. 忌冲对宫破耗公理 (Clash & Vulnerability)
- 任何宫位化忌（生年忌或宫干飞忌），其**对宫必定承受最大动荡波**：
  - **官禄化忌冲夫妻**：事业困顿波及婚姻破裂，或因过度投身工作导致情感荒芜；
  - **夫妻化忌冲官禄**：情感纠葛拖累事业前程，合伙人反目导致业务崩塌；
  - **财帛化忌冲福德**：求财劳碌导致身心崩溃失眠，严重内耗；
  - **福德化忌冲财帛**：心态焦虑导致盲目投资亏损，资本蒸发；
  - **田宅化忌冲子女**：家宅不宁动荡，资产缩水，合伙破散。

### 6. 大限应期捕捉公理 (Decadal Event Timing)
- **定数爆发点**：当大限重叠【来因宫】或【生年四化宫位】时，必触发不可逆转的人生重大里程碑；
- **破败大坎年**：当大限命宫或财官逢【自化忌冲对宫】时，锁定为重大破损收缩期，必须严守防线。
