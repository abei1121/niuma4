### 1. 小韭菜俱乐部会员卡 8 大深层缺陷全量修复与生产推送

针对 `https://github.com/abei1121/clubxiaojiucai`（本地定点：`/Users/hi/Documents/GitHub/clubxiaojiucai`），深入代码底层实施全栈安全审计，成功排除 8 项隐蔽 Bug，推送 commit `ff46150` 并解决 Cloudflare Pages 构建兼容性问题：

1. **TonConnect 2.0 签名鉴权漏洞与双重 SHA256 哈希重构 (`tonProofService.ts`)**：
   - 修复前：误用旧版 `'ton-safe-sign-magic'` 盐值且存在 `signature.length === 64` 放行漏洞；
   - 修复后：严格遵循 TonConnect 2.0 规范，使用 `0xffff ++ 'ton-connect'` 盐值与两轮 SHA256 哈希计算消息摘要，结合 Ed25519 公钥严谨执行 `nacl.sign.detached.verify` 验签。
2. **Telegram WebApp (TMA) 外部钱包签名锁死修复 (`useTonProof.ts`)**：
   - 修复前：在 TMA 环境中跳过 proof 生成，致使 Tonkeeper 等外部非 Telegram 钱包无法签名，管理员被锁死在只读观察模式；
   - 修复后：移除 TMA 旁路，统一声明 `{ tonProof: nonce }` 挑战，确保全平台钱包行为一致。
3. **Cloudflare Pages Node 20 编译环境锁与构建失败治理**：
   - 修复前：Tailwind CSS v4 与 Vite 6 硬性依赖 Node >= 20，Cloudflare Pages 默认 Node 18 构建持续崩溃，且缺少 `openLink.ts`；
   - 修复后：补齐 [`.nvmrc`](file:///Users/hi/Documents/GitHub/clubxiaojiucai/.nvmrc) 与 [`.node-version`](file:///Users/hi/Documents/GitHub/clubxiaojiucai/.node-version)（声明 `20.18.0`），创建 [`src/lib/openLink.ts`](file:///Users/hi/Documents/GitHub/clubxiaojiucai/src/lib/openLink.ts) 安全跳板，本地 `npm run build` 4.45s 零警告通过。
4. **React 依赖死循环与组件重绘风暴治理 (`useXiaoJiucaiClub.ts`)**：
   - 修复前：`fetchContractData` 未用 `useCallback` 稳定引用，导致 `useEffect` 每次渲染都重建定时器并死循环拉取；
   - 修复后：引入 `useCallback` 固化拉取逻辑，添加 `isMounted` 状态看门狗与安全的清除闭包。
5. **TON 价格预言机容灾三级降级架构 (`useTonPrice.ts`)**：
   - 修复前：单一依赖失效的外部接口，前台折算常态显示 0 或 NaN；
   - 修复后：重构为 CoinGecko -> OKX -> TonAPI 三级轮询降级池，增加 60 秒内存防抖缓存与保底兜底。
6. **移动沙箱协议跳转与 iOS Safari 滚动锁修复 (`openLink.ts` & `AdminPanel.tsx`)**：
   - 修复前：直接使用 `window.open` 与原生 Scheme，模态框注入 `touchAction: none` 导致 iOS 物理滚动破坏；
   - 修复后：使用 `Telegram.WebApp.openTelegramLink` 与 `openLink`，模态框改用 `overflow: hidden` 并在卸载时严格复原。
7. **多语言全量 Key 对齐与控制台未定义警告消除 (`translations.json`)**：
   - 补齐繁体中文、英文、韩文关于“铸造成功”、“特权介绍”等遗漏字典项。
8. **虚拟 DOM 重排错位与 Key 属性规范化 (`NFTDisplay.tsx`)**：
   - 消除动态权益列表与 NFT 列表中的 `key={index}`，替换为具有业务唯一性的 `key={tier.id}` 与 `key={item.address}`。
