## 三、 商业机密绝对隔离与封闭防护规范 (Zero-BYOK Policy)

### 1. 废除用户自定义 API (BYOK) 的底层动因
* **蜜罐服务器抓包风险**：若允许用户自定义 Base URL，有心用户可配置抓包地址，服务端发起的请求体将明文暴露完整的宗师核心提示词（中州派十四主星赋性、四重叠宫算法与钦天派自化串联公式）。
* **第三方中转平台审计风险**：聚合 API 平台及中转站后台普遍记录 Request Body，导致专有提示词外泄。

### 2. 全闭环安全架构
* **物理下线前端配置**：彻底删除 `NftCustomApiPanel.tsx`，前端不保留任何 API Key、Base URL 或 Model 输入框。
* **全局文案清洗**：移除所有语言包（中文简体、繁体、香港繁体、英文等）与组件中关于“接入自定义 API”的表述。
* **服务端私有闭环**：所有推演与追问请求统一收拢至服务端私密引擎直接调度，对外只下发流式渲染文本，商业提示词绝不出内网。
* **防泄密绝杀指令**：在中州派、钦天派及追问宗师提示词中注入安全红线指令，彻底拦截通过 Prompt Injection 越狱套话的企图。

## 五、 正统数术道统防坑与核心隐蔽缺陷治理 (Canon Defense Standard)

在工程持续演进中，提炼沉淀了以下八大命理与工程底层防坑铁律：

### 1. 繁简统一字典强映射（钦天四化零漏判）
* **根因与缺陷**：底层星曜字典与钦天四化存在繁简混杂，如 `廉贞/廉貞`、`破军/破軍`、`左辅/左輔`；若直接使用未归一化的字符串匹配，将导致特定生年天干下核心主星化曜彻底失效（如庚干武曲化权、天同化忌判定丢失，或丙干廉贞化忌计算失败）。
* **规制**：全站统一引用 `SI_HUA_MAP` 与 `st`（星曜繁体化标准映射函数），底层计算时强制先做繁简归一化；同时过滤万年历宜忌中返回的 `'无'` / `'無'` 等假值。

### 2. 正统紫微依农历正月初一换年（彻底解耦八字节气）
* **根因与缺陷**：八字以「立春」换年，而正统紫微斗数严格以「农历正月初一」换年。若误用八字库的 `solarTermsFourPillars` 作为紫微排盘年份干支，在除夕至立春之间出生的人群，生年天干整整错位一年，直接导致钦天派命理灵魂【来因宫】整整偏离一个大宫位。
* **规制**：紫微排盘生年干支与中心盘生年四化必须严格提取 `lunarFourPillars` / `chineseDate.yearly[0]`，坚决与节气库物理断开。

### 3. 宗师提示词中华道统繁体规范
* **规制**：服务端与客户端提示词构造器中的生年与运限四化标记，强制采用中华道统正统繁体 `['祿', '權', '科', '忌']`，杜绝繁简混杂。

### 4. 命主之锚全链路贯通
* **规制**：在排盘容器（`AstrolabeView`）与剧本模态（`CreatorScriptModal`）之间显式透传命主姓名（`profileName`），生成造物主剧本长图海报时右上角必具“命主之锚 · {profileName}”，杜绝空置。

### 5. 多语言万年历与节气全覆盖
* **规制**：黄历万年历多语言字典（`almanacTerms.ts`）补全简体节气键名（惊蛰、谷雨、小满、芒种、处暑），确保在俄文、越南文、英文界面下精准映射，并纳入造桥、修门、开渠、习艺等民间择吉活动。

### 6. 真太阳时经纬度东西经动态判定
* **规制**：经度展示一律采用 `{Math.abs(lon).toFixed(2)}°{lon >= 0 ? 'E' : 'W'}`，杜绝西方经度（西经）被粗暴硬编码为 `°E` 的学术硬伤。

### 7. 宣纸海报流式排版双防线（防撞车算法）
* **规制**：海报绘制引擎摒弃静态 Y 坐标，采用 `cursorY` 动态推移；底部认证印鉴与二维码基准点使用 `Math.max(1180, cursorY + 28)` 动态推演，并针对英文/西文引入空格断词分词器，100% 杜绝多语言长文与底部版块叠字撞车。

### 8. 后端天命能量 6:1 计费严格空值隔离
* **根因与缺陷**：全盘全局推演消耗 6 点能量，追问答疑消耗 1 点能量。若仅用 `req.question.is_some()` 判定追问，客户端在首次推演若传入 `question: ""` 或空白串，会被判定为追问，不仅只扣 1 点能量，且会错误挂载 `CREATOR_QA_PROMPT` 导致全盘命书解析降级。
* **规制**：后端采用 `req.question.as_ref().map(|q| !q.trim().is_empty()).unwrap_or(false)` 严格校验，杜绝空白参数偷跑计费与提示词降级。
