# 牛马1号 异地脱敏灾难恢复与冷备份守卫 (Disaster Recovery Vault)

## 概述
专职负责牛马1号核心资产的异地容灾与脱敏备份，保障在物理宿主机宕机、硬盘损毁或系统崩溃重装后，半小时内无损复活全部心智记忆、技能与控制面板。

## 灾备仓库定点
- **GitHub 私有灾备仓**: `git@github.com:abei1121/niuma1.git` (Private)
- **本地独立冷隔离区**: `/home/a/niuma1_vault/`
- **一键脱敏导出工具**: `niuma_backup` (软链接至 `/usr/local/bin/niuma_backup`)

## 核心备份资产清单 (总体积约 1.7MB)
1. **灵魂设定**: `/home/a/GEMINI.md` (行为铁律、硬件调度、通信纪律)
2. **记忆中枢**: `memory/jiyi.json` 与 `memory/jiyi.md`
3. **现役核心技能库**: `/root/.gemini/config/skills/` (全量同步)
4. **自研项目纯源码**:
   - `poly_mission_control` (Rust 后端 + Preact/Vite 前端，剥离 target 与 node_modules)
   - `telegram_bot_rust` (Rust 源码，真实 Token 自动转换为 `.env.example`)
   - `system_keeper_rust`、`lan_file_server_rust`、`proxy_health_checker_rust`
5. **系统维护工具与守护**: `systemd/*.service` 与核心维护脚本

## 常用灾备命令
1. **日常一键增量脱敏备份与推送**:
   `niuma_backup`
2. **全新机器灾难一键复活 (在新系统执行)**:
   ```bash
   git clone git@github.com:abei1121/niuma1.git /home/a/niuma1_vault
   cd /home/a/niuma1_vault
   chmod +x restore.sh sync_vault.sh
   bash restore.sh
   ```

## 安全红线与脱敏铁律
- 严禁真实 Telegram Bot Token、Hysteria 2 节点密钥、Tailscale 凭证入库。
- 严禁大视频文件（mp4/mkv）与编译缓存（target/dist）入库。
- 脚本内嵌安全审计器，一旦检测到未脱敏私钥立即熔断终止推送。
