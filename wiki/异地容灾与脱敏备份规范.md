# 牛马4号 异地脱敏灾难恢复与冷备份守卫 (macOS M2 专属版)

## 概述
专职负责牛马4号核心资产的异地容灾与脱敏备份，保障在物理宿主机宕机、硬件损毁或系统重装后，半小时内无损复活全部心智记忆、技能与控制面板。

## 灾备仓库定点
- **GitHub 私有灾备仓**: `git@github.com:abei1121/niuma4.git` (Private)
- **本地独立冷隔离区**: `/Users/hi/niuma/niuma4_vault/`
- **一键脱敏导出工具**: `/Users/hi/niuma/scripts/niuma_backup.sh` (软链接至 `/Users/hi/niuma/bin/niuma_backup`)

## 核心备份资产清单
1. **灵魂设定**: `/Users/hi/niuma/GEMINI.md` (行为铁律、硬件调度、通信纪律)
2. **记忆中枢**: `/Users/hi/niuma/memory/jiyi.json` 与 `/Users/hi/niuma/memory/jiyi.md`
3. **现役核心技能库**: `/Users/hi/.agents/skills/` (全量同步)
4. **自研项目纯源码**:
   - `poly_mission_control` (Rust 后端 + Preact/Vite 前端，剥离 target 与 node_modules)
   - `telegram_bot_rust` (Rust 源码，真实 Token 自动转换为 `.env.example`)
   - `system_keeper_rust`、`lan_file_server_rust`、`proxy_health_checker_rust`、`gemini_account_probe`、`agy_wrapper_rust`
5. **系统维护工具与守护**: macOS LaunchAgent 配置与核心维护脚本

## 常用灾备命令
1. **日常一键增量脱敏备份与推送**:
   `niuma_backup` 或 `/Users/hi/niuma/scripts/niuma_backup.sh`
2. **全新机器灾难一键复活 (在新系统执行)**:
   ```bash
   git clone git@github.com:abei1121/niuma4.git /Users/hi/niuma/niuma4_vault
   cd /Users/hi/niuma/niuma4_vault
   chmod +x restore.sh sync_vault.sh
   bash restore.sh
   ```

## 安全红线与脱敏铁律
- 严禁真实 Telegram Bot Token、Hysteria 2 节点密钥、OAuth Refresh Token 凭据入库。
- 严禁大视频文件（mp4/mkv）与编译缓存（target/dist）入库。
- 脚本内嵌安全审计器，一旦检测到未脱敏私钥立即熔断终止推送。
