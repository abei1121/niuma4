## 灾难恢复指南 (在全新 Mac mini 一键复活)

当硬件损坏重装系统后，执行以下步骤即可一键无损复活：

1. **拉取本私有仓**：
   ```bash
   git clone git@github.com:abei1121/niuma4.git /Users/hi/niuma/niuma4_vault
   ```
2. **执行一键复原**：
   ```bash
   cd /Users/hi/niuma/niuma4_vault
   chmod +x restore.sh sync_vault.sh
   bash restore.sh
   ```
3. **补充真实私钥与配置**：
   - 编辑 `/Users/hi/niuma/niuma1-main/projects/telegram_bot_rust/.env` 填入真实 TG Bot Token。
   - 确保 `/Users/hi/niuma/hysteria.yaml` 代理配置就绪。
4. **编译并启动守护进程**：
   ```bash
   cd /Users/hi/niuma/niuma1-main/projects/poly_mission_control/web_frontend && npm install && npm run build
   cd /Users/hi/niuma/niuma1-main/projects/poly_mission_control && HOME=/Users/hi cargo build --release
   cp /Users/hi/niuma/niuma1-main/projects/poly_mission_control/target/release/poly_mission_control /Users/hi/niuma/bin/
   /Users/hi/niuma/scripts/manage_services.sh restart
   ```
